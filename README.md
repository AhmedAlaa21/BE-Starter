# Learning Node.js & Express

A simple repository to learn Node.js and Express.js through hands-on examples.

## What You'll Learn

- Node.js basics
- Building web servers with Express
- Working with databases
- Creating REST APIs
- User authentication

## Getting Started

1. **Install Node.js**
   - Download from [nodejs.org](https://nodejs.org/)
   - Check it works: `node --version`

2. **Clone and run**
   ```bash
   git clone https://github.com/yourusername/nodejs-express-learning.git
   cd nodejs-express-learning
   npm install
   npm start
   ```

## What's Inside

```
01-basics/          # Hello World, modules, async code
02-express-intro/   # First Express server
03-routing/         # Routes and parameters
04-middleware/      # Understanding middleware
05-database/        # Connect to MongoDB
06-rest-api/        # Build a REST API
07-auth/            # Login and signup
```

## Learning Order

1. Start with `01-basics` to understand Node.js
2. Move to `02-express-intro` to build your first server
3. Work through each folder in order
4. Each folder has its own README with examples

## Helpful Resources

- [Node.js Docs](https://nodejs.org/docs)
- [Express Docs](https://expressjs.com/)
- [MongoDB Tutorial](https://www.mongodb.com/docs/)

## Running Examples

```bash
cd 02-express-intro
npm install
npm start
```

Then open `http://localhost:3000` in your browser.
